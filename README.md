# گنجور نو

پروتوتایپ تعاملی ریدیزاین آرشیو شعر فارسی، برای نمونه کار طراحی محصول.

این نسخه رسمی [گنجور](https://ganjoor.net) نیست. متن‌ها نمونه و آموزشی‌اند؛ سن سرودن و جای نقطه‌ها روی نقشه تقریبی است.

## چه چیزی را نشان می‌دهد

- خواندن شعر با لایه‌های معنی، تفسیر، حاشیه و پیوند
- اتاق خلوت، نشان و یادداشت روی همین دستگاه
- نقشه هم‌عصران، پل تأثیر، وزن، و موج تاریخ
- چیدمان راست‌به‌چپ، مناسب موبایل و دسکتاپ
