# گنجور نو

خوانش‌خانه شعر فارسی. متن، فهرست و صوت از رابط عمومی گنجور می‌آید. طراحی و ساخت: مریم جابری.

این سایت رسمی گنجور نیست.

https://maryamjaberi.github.io/ganjoor-no/

## ابزارها (`#/discover`)

- زمان و مکان: نقشه هم‌عصران، جای‌ها در شعر، درخت شاعران
- پیوندها: پل‌های تضمین، مردمان شعر (خاندان، پیوند و بیت گواه)
- زبان و صناعت: وزن‌ها، آرایه‌ها، واژه‌سنج، خوانش دولایه
- خواندن: فال حافظ، جستجو، کتابخانه من، داده‌ها
